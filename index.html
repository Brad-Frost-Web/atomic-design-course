Atomic Design Certification Course

Course Demos

Follow one project as it evolves from a handful of static HTML pages into a full, documented, and consumable design system — one level at a time. Each demo below is a live snapshot of the project at that stage.

The Levels

  • Level 1

    Static Designs

    →

    Plain, hand-written HTML pages and CSS. The starting point.
  • Level 2

    Introduce Components

    →

    The first reusable Web Component (a site header), built with Lit.
  • Level 3

    Full Component Adoption

    →

    The rest of the pages broken down into a proper Web Component library.
  • Level 4

    Design Token Adoption

    →

    Design tokens and theming via Style Dictionary, with multiple themes.
  • Level 5

    Documentation

    →

    A Storybook workshop for developing and documenting components.
  • Level 6

    Architecture

    →

    Tokens, components, and the app split into separate projects in an npm-workspaces monorepo.
  • Level 7

    Consumption

    →

    Three consuming apps — Eleventy, React, and PHP — using the same design system.
Each level also lives on its own git branch. See the repository README for setup instructions and how to run each demo locally.
